# Dashboard ยอดจัดเก็บ รายภาค / กลุ่ม

หน้า dashboard ไฟล์เดียว (`index.html`) แสดงยอดจัดเก็บแยกภาค กลุ่ม รายเดือน
มีกราฟเส้น/แท่ง ตารางความร้อน ข้อเสนอแนะอัตโนมัติ 5 ธีม และอัปโหลดไฟล์ Excel/CSV เพื่ออัปเดตข้อมูลได้

## วิธี deploy ด้วย GitHub Pages

1. สร้าง repo ใหม่บน GitHub (แนะนำ **Private** เพราะข้อมูลอยู่ในไฟล์)
2. อัปโหลด `index.html` และ `README.md` ไปที่ root ของ repo
   (หน้า repo > **Add file** > **Upload files** > **Commit changes**)
3. ไปที่ **Settings > Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` / folder `/ (root)` > **Save**
4. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

> หมายเหตุ: GitHub Pages ของ repo แบบ Private ใช้ได้เฉพาะบางแพ็กเกจ (เช่น GitHub Pro/Team)
> และถ้า Pages เป็น public ทุกคนที่มีลิงก์จะเห็นข้อมูลในไฟล์ได้

## วิธีอัปเดตข้อมูล

**แบบชั่วคราว (เฉพาะเครื่องที่เปิด):** กดปุ่ม "อัปโหลด / อัปเดตข้อมูล" บนหน้าเว็บ แล้วเลือกไฟล์ .xlsx / .csv
ข้อมูลจะถูกจำไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น

**แบบถาวร (ทุกคนเห็นเหมือนกัน):** ต้องแก้ข้อมูลตั้งต้นในไฟล์ `index.html`
ที่ตัวแปร `DEFAULT_ROWS` แล้ว commit ใหม่ (ให้ Claude อัปเดตให้จากไฟล์ Excel ใหม่ได้)

## รูปแบบไฟล์ข้อมูล

หัวคอลัมน์: `เดือน`, `ภาค`, `กลุ่ม`, `สัญญาทั้งหมด`, `เป้าค่างวด`, `เก็บได้`, `เก็บได้จำนวน`
(คอลัมน์ `%` ระบบคำนวณเอง)
