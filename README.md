# Dashboard ยอดจัดเก็บ รายภาค / กลุ่ม

หน้า dashboard ไฟล์เดียว (`index.html`) แสดงยอดจัดเก็บแยกภาค กลุ่ม รายเดือน
มีกราฟเส้น/แท่ง ตารางความร้อน ข้อเสนอแนะอัตโนมัติ วิเคราะห์ชั้นหนี้ (P/SM/NPL) 10 ธีม และอัปโหลดไฟล์ Excel/CSV เพื่ออัปเดตข้อมูลได้

## วิธี deploy ด้วย GitHub Pages

1. สร้าง repo ใหม่บน GitHub 
2. อัปโหลด `index.html` และ `README.md` ไปที่ root ของ repo
   (หน้า repo > **Add file** > **Upload files** > **Commit changes**)
3. ไปที่ **Settings > Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` / folder `/ (root)` > **Save**
4. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

> หมายเหตุ: GitHub Pages ของ repo แบบ Private ใช้ได้เฉพาะบางแพ็กเกจ (เช่น GitHub Pro/Team)

## วิธีใช้งานข้อมูล

หน้านี้ **ไม่ฝังข้อมูลไว้** และ **ไม่จำข้อมูล** เปิดมาจะว่างเปล่า
กดปุ่ม "อัปโหลด / อัปเดตข้อมูล" (หรือลากไฟล์ .xlsx / .csv มาวาง) เพื่อสร้าง dashboard
เมื่อรีเฟรชหน้า ข้อมูลจะหาย ต้องอัปโหลดใหม่ทุกครั้ง
(ไฟล์ข้อมูลอ่านในเบราว์เซอร์ ไม่ถูกส่งไปที่ใด จึงไม่มีข้อมูลหลุดขึ้น repo)

## รูปแบบไฟล์ข้อมูล

หัวคอลัมน์หลัก: `เดือน`, `ภาค`, `กลุ่ม`, `สัญญาทั้งหมด`, `เป้าค่างวด`, `เก็บได้`, `เก็บได้จำนวน`
(คอลัมน์ `%` ระบบคำนวณเอง)

**ข้อมูลชั้นหนี้ (ไม่บังคับ):** ต่อท้าย 4 ชุดคอลัมน์ ชุดละ 16 ชั้น (01–12, 14, 15, 17, 18) ตามลำดับ
จำนวนสัญญา / เป้าค่างวด / จำนวนสัญญาที่เก็บได้ / เก็บค่างวดได้ โดยมีแถวป้ายชื่อชุดอยู่เหนือหัวคอลัมน์
ถ้ามีข้อมูลนี้ จะแสดงส่วน "วิเคราะห์ชั้นหนี้" เพิ่ม

การจัดกลุ่มชั้นหนี้: P = 01, 02 · SM = 03, 04, 14, 17, 18 · NPL = ที่เหลือ (05–12, 15)
(แก้ได้ที่ตัวแปร `CLS_P` และ `CLS_SM` ใน `index.html`)
